# 论文方法的差速车适配

流程：局部已知地图 → 每车 FIRI 安全区域并共享 → 多序列采样队形配置 → 启发式选择与折线连接 → 分布式 MPPI → 差速车执行。

- `uniform` 使用统一缩放 `c+s r`；`affine` 使用一般仿射 `c+A r`，增加矩阵非退化及车间距约束。没有加入 RRT* 或 Bézier。
- 前端朝目标方向的半圆采样，按论文式 (7)–(11) 评价，先选最低代价再检查安全性，失败则结束该序列。用 Hungarian 求解式 (12) 的相同分配目标。
- MPPI 按 Algorithm 2 使用单一名义控制、Gaussian 噪声及加权原始噪声更新，`S=Δt×sum(ρ)`；移位后末项补初始控制。状态 `(x,y,theta,v)`，输入 `(a,omega)`，用步内平均速度积分，是差速离散适配。
- SFC 使用用户选定的 GCOPTER **旧版** FIRI，不能称为文献 [32] 新版完整实现。上游 `ZJU-FAST-Lab/GCOPTER` commit `e0444f6d47b84f972ced91746b05feb36ce1fd4f`，原样保留三个头文件和 MIT 许可。仅调用区域生成，不使用其建图或轨迹优化。
- 3D FIRI 输入 z=0 障碍点与车辆点种子，取二维截面，再按车半径和栅格半对角线收缩。默认4轮，检查锚点和障碍分离。上游出现过线搜索警告；几何检查通过不代表内部优化已收敛。

代码按 `world/sfc/guidance/formation/mppi/simulation/outputs` 分工，独立原生绑定在 `native/`，上游源码在 `third_party/gcopter_firi/`。

## 参数与运行

沿用表 I：MPPI `R=1120`、`P=35`，前端 `TS=P`，后端代价权重与距离阈值见 `paper_costs.py`、`mppi.py`。前端20序列、256候选、0.1–0.2m采样半径，以及 Δt=0.2s、温度1000、噪声和差速动力学界为本实现选值，不是论文公布参数。

随机场景50×40m、50个圆形障碍，半径0.5m为假设。地图种子独立，3m范围理想局部观测，未知栅格视为障碍。图中按真实圆形绘制。

```bash
formation/paper_formation/native/build_firi.sh
MPLCONFIGDIR=/tmp/mpl-formation OPENBLAS_NUM_THREADS=1 /home/eai/projects/env-rebuilt/bin/python scripts/run_paper_formation.py --scene random_circles --map-seed 1 --mode affine --seed 0 --max-steps 1000 --output results/paper_formation/strict_paper_20261113
```

改 `--mode uniform` 跑统一缩放；`--scene open` 跑空旷场景。环境使用已有 NumPy/SciPy/Matplotlib、g++ 11.4.0、系统 Eigen 和 ctypes，**本次未安装新包**。共享库由构建脚本生成，不提交二进制。

结果包含 `trajectory.png/svg`、局部放大图、轨迹及区域 NPZ、规划记录和 metrics；`controls` 是执行平均速度与角速度，另存加速度控制及速度历史。独立验收入口 `scripts/audit_paper_formation.py --regions`。本轮结果与限制见《论文差速仿射验收结果.md》，此前 `final_v5` 等目录均为旧实现结果。
