# 基于局部 RRT\* 与连续安全区域的仿射多机器人编队轨迹规划

## 1. 研究问题与总体思路

研究面向局部感知环境下的多机器人仿射编队实时轨迹规划。各机器人通过局部传感器获取周围障碍物信息，并共享必要的安全区域信息，由集中式规划器生成编队引导路径，再通过集中式轨迹优化获得满足安全与动力学约束的连续轨迹。

整体保留 Liu 等人《Sampling-Based Hierarchical Trajectory Planning for Formation Flight》的分层结构及滚动时域规划思想，但对其上层采样规划机制进行修改。

原论文在每个规划周期内，随机生成多条编队配置序列，通过单步启发式代价选择后续配置，并根据累计代价选择最终引导路径。该方法能够快速生成局部折线路径，但不同候选序列独立传播，无法充分复用已经发现的中间配置，也难以持续保留和改进不同的运动分支。

当编队从统一缩放扩展为一般仿射变形后，相似的编队中心位置可能对应不同的旋转、剪切及非均匀缩放状态。这些变形方式可能影响后续障碍物的通行可行性。因此，考虑利用局部 RRT\* 搜索树替代原论文多条独立候选序列的组织方式，同时保留原论文的目标构型引导和启发式评价机制。

该修改并非将局部规划替换为全局 RRT\*，而是在每个滚动规划周期内，利用当前局部环境信息构建一棵有限规模的编队配置树，从中提取局部折线路径，交由后端连续轨迹优化。

## 2. 仿射编队配置空间

考虑二维平面上的 \\(N\\) 个机器人，设参考队形中第 \\(i\\) 个机器人的相对位置为 \\(r_i\in\mathbb R^2\\)。

采用一般仿射变换描述编队：

\\[ p_i(q)=c+Ar_i \\]

其中

\\[ c\in\mathbb R^2,\qquad A\in\mathbb R^{2\times2} \\]

分别表示编队中心和仿射变换矩阵。

统一配置变量为

\\[ \boxed{ q=(c_x,c_y,a\_{11},a\_{12},a\_{21},a\_{22}) \in\mathbb R^6 } \\]

该表示能够统一描述编队平移、旋转、剪切及非均匀缩放。相比原论文的统一缩放模型，增加了编队变形自由度，使机器人能够通过更多不同的形状变化适应局部障碍环境。

由于各机器人位置对 \\(q\\) 呈线性关系，可以表示为

\\[ p_i(q)=E_iq \\]

其中 \\(E_i\\) 为由参考队形位置决定的常矩阵。

这一线性关系同时有利于安全区域构造、配置之间的连接认证以及后续连续轨迹优化。

仿射配置还需要满足机器人之间的最小距离，以及必要的形状限制，避免不可接受的退化、剪切和缩放。

## 3. 基于启发式引导的局部 RRT\*

在每个滚动规划周期内，以当前编队配置为根节点：

\\[ q_0=(c_0,A_0) \\]

在当前局部已知安全环境内构建 RRT\* 搜索树：

\\[ \mathcal T=(V,E) \\]

树节点为仿射编队配置，树边表示两个配置之间经过安全认证的连续运动。

### 采样与扩展

保留原论文朝向目标构型的采样引导思想。

编队中心主要沿局部目标方向采样，仿射矩阵则在允许的变形范围内随机生成，以探索不同的旋转、剪切和缩放配置。

对于随机样本

\\[ q\_{\mathrm{rand}}=(c\_{\mathrm{rand}},A\_{\mathrm{rand}}) \\]

通过配置距离选择最近节点：

\\[ q\_{\mathrm{near}} = \arg\min\_{q_i\in V}d_W(q_i,q\_{\mathrm{rand}}) \\]

配置距离可根据各机器人的实际位置变化构造：

\\[ d_W^2(q_a,q_b) = \sum\_{i=1}^{N} \\|p_i(q_a)-p_i(q_b)\\|^2 \\]

然后通过 Steer 产生新的候选配置，并执行安全连接检查。

与原论文逐步选择当前最低代价配置不同，RRT\* 可以保留多个具有不同仿射变形的节点，使这些节点在后续采样中继续获得扩展机会。

目标引导的作用是减少无意义的回绕和局部搜索开销，但不应完全禁止必要的侧向或后退运动，以免限制绕障能力。

### ChooseParent 与 Rewire

利用作者原有的启发式评价设计，构造适合 RRT\* 的路径代价。

原论文的缩放偏好扩展为仿射形状偏好：

\\[ J\_{\mathrm{shape}}(q) = \\|A-A\_{\mathrm{des}}\\|\_F^2 \\]

同时保留障碍风险和运动连续性评价。

对于树边 \\((q_i,q_j)\\)，考虑

\\[ \ell(q_i,q_j) = w_d\ell\_{\mathrm{motion}} +w_s\ell\_{\mathrm{shape}} +w_r\ell\_{\mathrm{risk}} \\]

其中各项沿连接路径累计，避免单纯因为节点数量不同而改变路径评价。

节点维护从根节点到当前配置的累计代价：

\\[ J(q_j)=J(q_i)+\ell(q_i,q_j) \\]

ChooseParent 从附近安全可连接节点中选择累计代价较低的父节点，Rewire 则尝试通过新节点改善已有节点的到达代价。

原论文包含相邻运动方向变化的连续性惩罚。若直接将该惩罚纳入路径代价，重连时需要重新计算受影响的转向代价及子树代价，以保证代价一致性。

### 局部引导路径选择

局部规划不要求在当前周期到达最终任务目标。

在有限搜索时间内，从树中选择具有足够推进距离、累计代价较低的候选路径。

目标构型用于终点评价，例如

\\[ F(q_i) = J(q_i)+w_gd_W(q_i,q\_{\mathrm{goal}}) \\]

最终提取从根节点到选定节点的配置序列：

\\[ \Pi_q=\\{q_0,q_1,\ldots,q_K\\} \\]

由此得到每个机器人的折线路径：

\\[ \Pi_i=\\{E_iq_0,E_iq_1,\ldots,E_iq_K\\} \\]

相比原论文独立序列传播，RRT\* 的潜在优势在于共享搜索前缀、保留不同仿射变形分支，以及利用重连持续改善已有路径。

但树结构不保证发现所有不同拓扑类别的路径，也不保证在有限时间预算内一定优于原论文，需要通过实验验证。

## 4. 安全区域构造与连接认证

考虑两种安全区域实现：原论文的 SFC，以及我们此前设计的方向性配置空间安全区域。

### SFC 路线

原论文为每个机器人构造工作空间中的凸安全区域：

\\[ \mathcal P_i = \\{p:H_ip\leq h_i\\} \\]

利用仿射位置关系，可得到编队配置空间中的凸区域：

\\[ \boxed{ \mathcal C\_{\mathrm{SFC}} = \\{q:H_iE_iq\leq h_i,\ \forall i\\} } \\]

当两个配置属于同一个有效区域时，它们之间的线性插值满足对应的环境避障约束。

不同局部区域之间的连接，则需要确认存在共同有效的安全约束，不能仅因两个配置分别安全就认定直线连接安全。

### 方案 A 路线

根据当前编队配置下各机器人与障碍物之间的安全距离、分离方向以及全局安全界，直接构造配置空间中的凸安全区域。

对于仿射编队，典型方向性约束为

\\[ \boxed{ n\_{ij}^{T}(\Delta c+\Delta A r_i) \geq-m\_{ij} } \\]

其中 \\(n\_{ij}\\) 为有效分离方向，\\(m\_{ij}\\) 为安全裕度。

与原先的 \\(SE(2)\\) 刚性编队区域相比，仿射表示下各机器人位置变化对配置变量呈线性关系，因此不再需要对旋转位移作相同形式的保守近似。

完整安全区域还需结合未显式处理障碍物的安全约束，以及机器人之间的碰撞约束。

对于机器人间的最小间距

\\[ \\|A(r_i-r_j)\\|\geq d\_{ij}^{\min} \\]

可以采用局部有效的线性充分条件构造凸安全内近似，或使用其他经过认证的连接检查方法。

两种区域均用于 RRT\* 的边连接认证，也可在后端轨迹优化中作为连续时间安全约束。

## 5. 集中式连续轨迹优化

局部 RRT\* 负责生成几何安全的仿射配置折线路径，不直接处理完整动力学轨迹。

后端根据得到的配置路径：

\\[ q_0\rightarrow q_1\rightarrow\cdots\rightarrow q_K \\]

构造连续仿射参数轨迹：

\\[ q(t)=(c(t),A(t)) \\]

从而得到各机器人的位置轨迹：

\\[ \boxed{ p_i(t)=c(t)+A(t)r_i } \\]

进一步有

\\[ \dot p_i(t)=\dot c(t)+\dot A(t)r_i \\]

\\[ \ddot p_i(t)=\ddot c(t)+\ddot A(t)r_i \\]

因此，可以直接在统一的仿射参数轨迹上施加各机器人的速度、加速度及更高阶导数约束。

轨迹可以使用分段多项式或 Bézier 曲线表示，并施加位置及必要阶数导数的连续性约束。

对于对应的凸安全区域 \\(\mathcal C_k\\)，要求该段 Bézier 曲线的全部控制点属于 \\(\mathcal C_k\\)，即可利用凸包性质保证：

\\[ q(t)\in\mathcal C_k \\]

从而获得连续时间的环境避障保证。机器人之间的安全约束同样需要包含在区域认证中。

对于微分平坦系统，还可以根据平坦输出及其导数恢复机器人控制输入。差速车的平坦输出可选为位置，但需要处理零速度奇异性和转向角速度等非凸约束；四旋翼则需要考虑推力、姿态和控制输入的实际限制。

因此，安全凸区域可以简化后端的几何避障约束，但并不意味着完整动力学轨迹优化一定是凸问题。

## 6. 滚动时域执行

整体采用滚动重规划方式。

每个规划周期，根据各机器人最新的局部环境信息，更新 SFC 或方案 A 安全区域，以当前编队状态为起点进行有限预算的 RRT\* 搜索。

选取局部引导路径后，集中式优化器生成连续轨迹，机器人只执行其中一部分，然后根据新的状态和环境信息重新规划。

规划器需要保证新轨迹与当前实际运动状态合理接续。同时，对未知区域以及突然发现障碍物的情况，需要保留安全停止或可行备用轨迹；仅有几何安全折线并不能自动保证滚动规划始终可行。

## 7. 方案的研究价值与待验证问题

相对于原论文，目前方案的主要变化不是将统一缩放简单扩展为一般仿射变形，而是重新设计局部随机采样结果的组织和利用方式。

原论文通过多条独立的随机候选序列，结合单步启发式评价获得局部路径。我们则尝试利用目标引导的 RRT\* 树组织六维仿射配置，保留不同变形分支，并通过 ChooseParent/Rewire 改善候选路径。

与直接采用非凸轨迹优化搜索多个变形方案相比，该设计仍然保持几何前端的快速单步扩展，将连续时间动力学优化集中到最终选定的路径上。

后续需要重点验证三个问题：六维仿射配置下的有效扩展率是否足够高；树结构是否能在相同时间预算下，比原论文独立候选序列获得更好的路径推进和路径质量；SFC 与方案 A 哪一种更适合实时连接认证及后端轨迹约束。

最终形成的研究方案可以概括为：

\\[ \boxed{ \begin{gathered} \text{多机器人局部环境感知}\\\ \downarrow\\\ \text{SFC / 仿射配置空间安全区域}\\\ \downarrow\\\ \text{目标启发式引导的六维局部 RRT\*}\\\ \downarrow\\\ \text{安全编队配置折线路径}\\\ \downarrow\\\ \text{集中式连续轨迹优化}\\\ \downarrow\\\ \text{执行与滚动重规划} \end{gathered} } \\]

当前应以局部 RRT\* 替代原论文独立候选序列作为前端的主要研究方向，以两种安全区域构造方法作为可比较的实现路线，后端统一采用仿射参数连续轨迹优化。

这一方案在几何和优化建模上具有可行性，但其相对于原论文的实时效率、复杂障碍适应能力及独立算法贡献，仍需进一步验证。
