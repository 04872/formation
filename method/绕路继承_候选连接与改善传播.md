# 绕路继承：候选连接与改善传播

## 术语与结论修正

区域规划的原流程是：sample → select → Steer 构造新区域 \(C_{\rm new}\)，并认证其与扩展父区域的交叠 → ChooseParent 为新区域首次选父挂树 → Rewire 尝试改变已有节点的父节点。本文此后用“连接阶段”指新区域首次挂树，用“重连”或 Rewire 指已有节点改父；固定图里的“边”是抽象图边，不应不加区分地称为规划器的首次连接。

ChooseParent 不决定新区域的几何形状。普通非目标叶子的首次挂树即便带来低代价前缀，也不会直接降低旧目标路径代价。目标代价可以通过两条途径改善：一是短前缀经 Rewire 替换旧最优链的下游前缀；二是新分支独立形成到目标的完整可行路径，且其代价低于当前最优目标代价，此时无需改父旧节点。

对于第一条途径，设旧目标路径经过 \(a\) 后绕行至 \(b\)，\(b\) 的旧入口为 \(e_b\)、旧前缀代价为 \(g_b\)、该入口之后的旧后缀代价为 \(L_b\)。从 \(a\) 经新分支到同一入口的代价为 \(G_{\rm new}=g_a+L_{\rm new}\)。对 \(b\) 或适当的后缀节点实际完成无环、经认证的 Rewire，且新前缀严格更短，才能沿保留的后缀降低其路径代价；若 \(b\) 位于当前最优目标链，固定 \(e_b\) 且 \(G_{\rm new}<g_b\) 时，原目标路径代价从 \(g_b+L_b\) 降为 \(G_{\rm new}+L_b\)。若 \(b\) 不在当前最优目标链上，仅由其前缀改善不能推出当前最优目标代价下降。新增的分支也可以复用旧的可达区域，不一定要新造区域；区域或入口发生变化本身并不保证目标改善。

下文的点 RRT* 固定点集、扩大邻域及 Dijkstra 反事实，只证明这批已有点在扩大候选边后能够支持更低代价的父关系；Dijkstra 可能同时改变多个父关系。它不证明首次挂树是绕路原因，也不能判定区域 A 的 Steer、首次选父与后续重连哪个主导。dense seed 2 的八区域 oracle 说明区域模型的表达能力，不证明 Steer 能在线自动生成这些区域。

后续诊断应依次区分：更短通道中是否出现适当区域；这些区域是否获得低代价、可行的前缀；旧后缀是否触发并允许改父。下文固定图数学保留为诊断，不能将其概括成“连接太局部”。本节不提出算法修改。

## 问题与固定图结论

一条代价较低的前缀出现后，已有子树代价可以随之下降，但这不等于算法重新检查了它与其他分支的全部旧连接。于是，树可能保留本来可通过旧点之间的连接消除的绕路。另一方面，即使反复检查了所有允许的连接，如果更短路线所需的连接不在候选集合内，树的优化也无法产生这条路线。

本次只诊断 `formation.baselines.RRTStar` 的 **forest、seed 0、6000 次原始提议**。固定最终采样点及其原有目标连接，原半径 0.3 内确实存在未使用的可行松弛边；但在该固定图上把改善传播到最短路后，目标代价完全不变。对同一批点扩大允许候选边的半径，离线目标代价下降 14.49%。因此，这个实例的固定点反事实表明，仅反复优化原半径图的旧边不能改善目标，而扩大图的候选边可以；它不识别在线各阶段的因果责任。这个结论不推广到其他种子，也不直接证明区域规划器的原因。

## 固定图上的推导

令有向图 \(G=(V,E)\) 表示已固定的状态和算法允许、且已验证可行的连接，边代价 \(c(u,v)\geq 0\) 固定。令起点 \(s\) 的当前代价 \(g(s)=0\)，其他 \(g(v)\) 是当前可行树路径的准确代价；目标可以看作通过已有目标连接到达的终点。假设图中存在一条从起点到目标、总代价严格小于当前目标代价的路径。

该路径上必有至少一条边满足

\[
g(u)+c(u,v)<g(v).
\]

否则，每条边都有 \(g(v)\leq g(u)+c(u,v)\)，从起点沿路径逐边相加，将得到当前目标代价不大于该路径代价，和假设矛盾。这样的边称为相对于当前 \(g\) 的残余可松弛边。某些边最初没有改善机会，前面的节点降价后才会出现机会，所以只扫描一次当前残余边不够。

在固定有限图、准确边代价的条件下，公平地反复处理仍可改善的边，或用正确的最短路算法，可以消除残余并得到固定图最短代价。单次重连以及对子树的代价传播不等于重新检查所有跨分支连接。另一方面，即便固定图内部求解完全充分，也只能达到该图自身的最短路；没有被允许或没有被发现的连接不会因此出现。这是候选连接集合对树内优化结果施加的上限。

这里的论证依赖状态与边代价固定。区域规划中入口移动会改变后续段代价，出口保护也影响可接受更新，不能直接将区域当作上述固定代价点图并宣称同样结论。

## forest seed 0：固定点反事实

按原实验参数重放 RRT*：`step=0.3`、`goal_bias=0.1`、`rewire_factor=1.1`、额外 clearance 0.02、边检查间距 \(d_W=0.02\)。6000 次提议得到 2896 个点、2895 条树边和 758 条已知目标连接，原树目标代价 \(J=16.7749505463\)。两次离线分析使用同一确定性重放所得状态集、原树边及已有目标节点/目标边，未增加采样点或新目标边。yaw 按周期距离处理。半径内候选边按需用原有碰撞检查验证，已知树边保留；随后用 Dijkstra 求固定图最短路。

| 固定点图 | 原半径 | 未截断公式半径 |
|---|---:|---:|
| 半径 | 0.3 | 1.8785825027 |
| 半径内无向点对 | 18123 | 267787 |
| 原代价下有松弛潜力的点对 | 7 | 89673 |
| 其中碰撞可行 | 6 | 42676 |
| 离线碰撞检查点对总数 | 2872 | 102613 |
| 其中可行 / 不可行 | 2871 / 1 | 46463 / 56150 |
| 最短路改善的点数 | 13 | 2890 |
| 固定图最短目标 \(J\) | 16.7749505463 | 14.3440534345 |

未截断半径按最终节点数使用 \(\gamma(\log(n+1)/(n+1))^{1/3}\) 计算，只是这个固定图反事实的连接范围，并非原运行实际使用的半径。邻居点对是几何候选总数，不等于全部经过碰撞验证的边数；Dijkstra 只验证当时可能改善距离的候选边，故无需验证所有点对。两种半径下所有原树边都在半径内。碰撞检查是与原方法一致的离散检查，不是连续碰撞证明。

离线耗时分别为：半径 0.3 的重放 3.205 s、邻接构造 0.034 s、初始残余检查 0.003 s、Dijkstra 0.115 s，记录的阶段合计 3.357 s；较大半径依次为 3.253 s、0.755 s、14.359 s、2.354 s，合计 20.721 s。碰撞检查分别累计 0.106 s 和 16.379 s，已包含在残余检查与 Dijkstra 阶段内，不能重复相加；程序启动和未单独计时的零星开销不在阶段合计中。两次重放耗时也各自计入上述合计。这些都是诊断时间，不能作为在线规划时间或等预算比较。

## 区域算法中的对应问题和边界

区域方法中存在不同但相互关联的限制：严格 overlap 和安全余量决定现有区域是否具备被认证的连接；候选选择最多保留 16 个邻居，可能使其他可连接区域未被尝试；覆盖样本直接跳过扩展，可能不生成用来跨越缺口的新证书。前者和证书缺口涉及可表示的连接集合，候选截断涉及实际检查范围；它们都不能仅凭点 RRT* 的半径实验定量归因。即便区域对能够连接，入口可变、出口保护及子树代价更新又构成另一个优化问题。

`exit_compensated_rrtstar.py` 的 `_commit` 更新父子关系和入口，标记直接子节点做 local 工作，并沿现有子树传播代价和目标缓存；它不会因为前缀降价而扫描所有跨树旧邻居并重新排队。`_service_local` 针对当前父节点求解，既有 rewire 队列仍会继续服务，新区域插入时也会生成邻居重连机会，因此不能说旧连接永远不会被再次检查。具体实现见 [`_commit`](../formation/exit_compensated_rrtstar.py#L232)、[`_service_local`](../formation/exit_compensated_rrtstar.py#L366) 和新节点连接逻辑。

另一个独立的 dense seed 2 离线见证沿已知路线从 368 个候选中选出 8 个新区域，形成代价 19.0930 的严格认证链，说明该见证中缺少的连接可由少数桥区域表达；候选依赖已知见证路径，在线如何发现和选择桥区域仍未解决。详见 [替代分支草案](区域绕路_替代分支增量生长草案.md)。这不能推导为应直接执行全局图搜索，也不能作为 forest 固定点实验的统计结果。

## 已撤回的候选方向

此前建议按需新增认证区域并拓宽邻接，作为当前推荐予以撤回：这是尚未论证的扩展改动，不是原有首次挂树流程的描述。已有严格交叠但未被尝试的区域对，与没有直接交叠、需要额外证书才能表达的路径仍是可分别检查的诊断对象。单纯增加现有树的回写次数不能补上缺失的图边。

此前推导中，固定目标区域入口 \(e_b\)，若前缀末端为 \(a\)，当前可行前缀代价为 \(g_a,g_b\)，则同入口前缀改善的必要条件为

\[
g_a+d_W(e_a,e_b)<g_b.
\]

若新短链通过严格认证、其到同一入口的真实代价 \(G_{\rm new}(e_b)<g_b\)，且接回不形成环，实际重连后才可保留原有后缀并降低该路径代价；其对当前目标的影响还取决于目标链，如文首所述。该下界仅针对当前前缀，不能永久剪枝其他未来前缀；它本身不是已验证的在线机制。有限近邻候选本身不保证渐近最优。
